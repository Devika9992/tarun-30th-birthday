TARUN'S 30TH BIRTHDAY WEBSITE — SETUP GUIDE

1. Keep the folder structure exactly as it is.
2. Double-click index.html to preview the website on your computer.
3. The website already contains the 13 photos supplied in the chat.
4. Music is optional. To enable the music button, place your legally obtained MP3 file in this folder and name it exactly:
   audio.mp3
5. To change text, open index.html in Notepad/VS Code and edit the text between the HTML tags.
6. To publish free, upload this entire folder to a static host such as GitHub Pages or Netlify.

IMPORTANT:
- Do not rename the images unless you also update the corresponding image paths in index.html.
- The website is designed to work without music too.
- The 30 hidden hearts are intentionally subtle and scattered across the page.

FILES:
index.html  = website content
style.css   = design and animations
script.js   = interactions
images/     = your photos
audio.mp3   = optional music file (you add this yourself)
