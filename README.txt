TARUN'S 30TH BIRTHDAY WEBSITE — FROM HIS WIFE

This is a fresh birthday website focused only on Tarun's 30th birthday and a message from his wife.
It intentionally does NOT mention the earlier friendship/Facebook story.

FILES
- index.html
- style.css
- script.js
- images/ (all 13 photos)

HOW TO USE
1. Extract this ZIP.
2. Open index.html in a browser to preview it.
3. For GitHub Pages, upload index.html, style.css, script.js and the entire images folder into the repository root.
4. Then enable GitHub Pages from Settings > Pages.

NOTES
- The site uses Google Fonts, so fonts require an internet connection.
- All photos are stored locally in the images folder.
- No copyrighted music is included.
